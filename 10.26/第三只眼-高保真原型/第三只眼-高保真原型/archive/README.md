# 设计归档

这里保存 Stitch 导出的原始备选稿与一次性迁移脚本，**不参与正式导航**，仅用于答辩时说明设计取舍。

## originals/

| 文件 | Stitch 原稿 | 说明 |
| --- | --- | --- |
| `home-alt-1.html` | `_3` | 首页备选 A：能力仪表盘式信息组织 |
| `home-alt-2.html` | `_5` | 首页备选 B：品牌叙事式视觉方向 |
| `observe-workbench-alt.html` | `_4` | 观察工作台早期布局：单列证据流 |
| `speaking-report-alt.html` | `ai_2` | 说课报告早期布局：雷达图优先 |

归档页已接入本地 `app.css`，顶部有「设计归档」提示条，页内链接统一指回现行页面。原始导出文件（含 `code.html` 与截图）保留在项目外层的 `_stitch_raw/`。

## scripts/

| 文件 | 用途 |
| --- | --- |
| `migrate.py` | 把 `_1` / `_2` / `ai_1` 迁移为 `pages/` 下的三个正式页面 |
| `make_archive.py` | 把 `_3` / `_4` / `_5` / `ai_2` 整理为本目录的 `originals/` |

两个脚本都使用绝对路径、只运行一次。正式页面已在迁移后手工补充导航、状态与交互，**不要重复运行脚本覆盖现网页面**。
