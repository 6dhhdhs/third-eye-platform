# 第三只眼 · 产品演示页

> 依据《智能学习平台 PRD 需求规范》V1.0（2026-10-08）整理的产品可视化陈列页。
> 用于小组汇报、答辩展示与评阅者快速理解项目全貌。

---

## 一、这是什么

一个**单文件静态陈列页**，把 PRD 里已经写定的内容集中呈现出来：

1. **PRD 要求的核心功能板块** —— F-01 ～ F-10 共 10 个功能模块，标注 P0/P1/P2 优先级，两个特色核心模块单独高亮
2. **主要页面与最核心的状态** —— P-01 ～ P-15 共 15 个页面，每张卡片含线框示意图、建议路由、核心内容、主要去向，以及该页最需要被设计出来的核心状态
3. **产品设计配色与功能模块** —— PRD 10.2 的 10 个设计令牌色卡（含 WCAG 实测对比度）、按钮/输入框/进度条/卡片/日历组件样例、字号阶梯、8px 间距系统、响应式三档断点
4. **不做具体逻辑** —— 本页**不含任何产品逻辑**，是纯静态展示

---

## 二、如何查看

**双击 `index.html`**，用 Chrome / Edge 打开即可。无需服务器、无需联网、无需安装任何环境。

页面顶部是吸顶导航，可点击跳转到九个区块。全部图形由 CSS 与内联 SVG 绘制，**不引用任何外链资源**。

## 六、配色执行的硬约束

PRD 10.2 明确禁止「`#8FAFC8` 作为白底小字号文字」，因为浅蓝与白底对比度仅 **2.30:1**，远低于 AA 要求的 4.5:1。本页严格照办：

- **主蓝一律用作填充，不作字色**。主蓝底元素一律配 `#253B4A` 文字（**5.07:1**，达 WCAG AA）
- 需要「蓝色文字」时改用 PRD 令牌 `--focus-outline #395A73`（白底 **7.28:1**，AAA）
- Hero 大标题的「只眼」二字同样遵守此约束：用**主蓝底 + 深蓝灰字**的高亮块，而非蓝色文字

各令牌在白底上的实测对比度（按 WCAG 相对亮度公式计算）：

| 令牌 | 色值 | 白底对比度 | 等级 |
| --- | --- | ---: | --- |
| `--text-primary` | `#253B4A` | 11.65:1 | AAA |
| `--focus-outline` | `#395A73` | 7.28:1 | AAA |
| `--text-secondary` | `#526778` | 5.88:1 | AA |
| `--danger` | `#A84646` | 5.79:1 | AA |
| `--success` | `#3C7862` | 5.18:1 | AA |
| `--brand-blue`（作字色，**禁止**） | `#8FAFC8` | 2.30:1 | 不达标 |

组合对比度：`#253B4A` on `#8FAFC8` = **5.07:1**（主按钮）；`#253B4A` on `#EDF3F8` = **10.41:1**；`#526778` on `#F7FAFC` = **5.61:1**。
