## 一、迁移到第三只眼时，我做了 6 个优化（不是照抄）

1. **收敛颜色**：参考图有三个抢眼的强调色（蓝 + 紫 + 青绿），放在教育产品上会像营销页。V2 只留「主色 + 语义色」两级，品牌蓝 #8FAFC8 降为高亮/进度色。
2. **深色卡只给一个主角**：Learnify 的黑色 hero 卡是全页焦点，第三只眼也只有一处该这么重——首页欢迎区。其余页面用白卡，避免每页都"黑一块"。
3. **统计卡从 4 个减到 4 个但换语义**：不变形，把 Enrolled/Completed 换成「已学课程 / 完成评课 / 观察时长 / 能力分」，学生看得懂。
4. **表格行高 56、去掉竖线**：参考图信息密度低、留白大，适合仪表盘；但观察记录表列多，行高 56 刚好。
5. **对比度提上来**：两张图的次要文字都偏浅（灰 #9AA4B2 级别），课程项目要过无障碍验收，V2 统一提到 #5B6B7C。
6. **头像用字母**：参考图是真人头像/3D 插画，你们没有真实用户素材，统一用字母头像（「林」）避免假人。

## 四、这套风格专属的微调口令

| 想要的效果 | 这么说 |
| --- | --- |
| 更像左图 | 「hero 卡改成纯黑 #0B1117，三个环用青/紫/青绿渐变」 |
| 更像右图 | 「主色换成青绿 #0F766E，卡片阴影再淡一点，字体加圆润」 |
| 降噪 | 「去掉所有发光效果和渐变，只留纯色描边环形」 |
| 提对比 | 「次要文字统一加深到 #5B6B7C」 |
| 统一圆角 | 「所有卡片圆角固定 24，图标芯片 14，按钮全胶囊」 |
| 要移动端 | 「同一页生成 390 宽版本，侧栏收进底部 Tab」 |
| 图表统一 | 「所有图表改成细线 8px、带浅色轨道底」 |

## 五、落地时特别注意

1. **别把深色卡铺满每一页**。V2 的深色只有三处：登录左栏、首页 hero、报告页 hero。铺多了会变"深色主题"，和你 PRD 的白底品牌冲突。
2. **圆角 24 只给卡片**，按钮统一 999 胶囊，输入框 12——参考图就是这样分层的，混用会显脏。
3. **环形指标最多三个**，四个以上就退化成装饰。
4. 导出后照旧只抄视觉：改 `prototype/pages/*.html`，保留 `layout.js` 体系与交互脚本。
5. 上线前跑 `npm run build:css`，把新令牌（画布 #F2F5F9、卡片 24）补进 `tailwind.config.js`。
