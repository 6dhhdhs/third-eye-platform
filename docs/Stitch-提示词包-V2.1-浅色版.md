## 一、参考图拆解：真正该学的是"轻"

| # | 特征 | 怎么落地 |
| --- | --- | --- |
| 1 | 画布与卡片分离 | 浅灰画布 + 纯白卡，靠阴影分层，不靠颜色 |
| 2 | 大圆角 | 卡片 24、图标芯片 14、按钮全胶囊 |
| 3 | 极柔阴影 | `0 6px 20px rgba(16,40,64,.05)`，几乎看不见 |
| 4 | 强调色只做点缀 | 主色只出现在按钮、进度、环形、选中态 |
| 5 | 数据可视化占版面 | 环形、细横条、柱状，线宽 8 |
| 6 | 状态药丸 | 浅底 + 深字，不用实心撞色 |

## 四、如果还觉得重，按这个顺序继续减

| 还想更轻 | 这么说 |
| --- | --- |
| 去掉阴影 | 「所有卡片去掉阴影，改成 1px #E6ECF2 描边」 |
| 提亮画布 | 「画布改成 #FAFBFC，卡片保持纯白」 |
| 降低对比 | 「主色改为 #6E93AB，按钮改成浅蓝底深字」 |
| 减少色块 | 「所有 tint 卡取消，只保留白卡」 |
| 更幼圆 | 「卡片圆角改成 28，按钮高度加到 52」 |

## 五、落地注意

1. 这套风格的核心是**留白和分层**，不是颜色。空白不够就会显脏，卡片间距至少 20。
2. 主色只出现在 6 个地方：主按钮、导航选中、进度条、环形描边、今天日期、图标芯片。别多。
3. tint 卡（#EAF3FB）一页最多两处，第一行一个、第四行一个，再多就花。
4. 导出后照旧只抄视觉，改 `prototype/pages/*.html`，保留 `layout.js` 与交互脚本。
5. 新令牌要补进 `tailwind.config.js`：画布、卡片圆角 24、阴影、tint 色，然后 `npm run build:css`。
