## 五、核心：打卡状态机（PRD 5.3.4 五态逐条落地）

| 状态 | 页面文案 | 按钮行为 | 触发方式 | 截图 |
| --- | --- | --- | --- | --- |
| 未登录 | 登录后开启今日学习 | 「登录」可点击 | 演示台切未登录 | `p03-06` |
| 今日未达标 | 完成一项学习任务后即可打卡 | 「去学习」可用；打卡**禁用 + 文字说明原因** | 三项任务全未完成 | `p03-01` |
| 已达标未打卡 | 今天的学习任务已完成 | 「完成今日打卡」可点击 | 任一任务完成 | `p03-02` |
| 已打卡 | 今日已打卡，继续保持！ | 打卡按钮禁用 + 对勾图标 | 记录含今日 | `p03-03` |
| 提交失败 | 暂时无法保存，请重试 | 「重试」可点击，**不新增重复记录** | 演示台开「模拟保存失败」 | `p03-04` |

### 5.1 有效学习任务（PRD 5.3.3）

页面列出三类任务：**课程学习 / 课堂观察 / 说课训练**，任一项完成即获得当日打卡资格。按 PRD 5.3.3 原文要求，界面上以「演示说明」明确标注这些为**模拟**任务，不声称已实现真实学习行为核验。

### 5.2 统计规则（PRD 5.3.5）

- **每日最多计入一次**：以自然日为唯一键，同日重复操作不增加天数；已打卡后按钮直接禁用，从源头防止重复提交
- **连续天数**：今天已打卡 → 从今天向前连数；今天未打卡但昨天已打卡 → 截至昨天；更早中断则从 0 开始；**历史累计天数不因中断清零**（因此「累计打卡」与「连续打卡」是两个独立指标）
- **日历双重标识**：完成日 = 主蓝底 + 对勾图标 + `aria-label`；未完成日 = 中性色 + 文字；**不靠颜色单独区分**（`10.4` `10.6`）

### 5.3 数据一致性（PRD 11.2）

未登录时，统计数字显示 `—`、日历不标出任何完成日、标题改为「最近七日（登录后显示打卡记录）」。目的是避免把上一位用户的打卡记录展示给当前访客，保证首页与个人中心的打卡数据同源。

## 九、视觉规范执行（PRD 10）

`:root` 中直接落地 PRD `10.2` 给定的设计变量，未自行改色：

```css
--brand-blue: #8FAFC8;    --brand-white: #FFFFFF;
--blue-light: #EDF3F8;    --blue-lighter: #F7FAFC;
--text-primary: #253B4A;  --text-secondary: #526778;
--border-default: #DAE5ED; --focus-outline: #395A73;
--danger: #A84646;        --success: #3C7862;
--radius-card: 16px;      --radius-control: 10px;  --space-unit: 8px;
```

- **主按钮 = `#8FAFC8` 填充 + 深蓝灰文字**。PRD 明确禁止白底小字号使用主蓝（对比度不足），因此本页所有主蓝底元素一律配 `#253B4A` 文字
- 次级按钮 = 白底 + 蓝边；文字按钮用于低权重操作
- 字体栈 `"Microsoft YaHei","PingFang SC",system-ui,sans-serif`；正文 16px、行高 1.6
- 页面最大宽 1200px，间距走 8px 系统
- **封面与图例一律使用 CSS 几何图形与内联 SVG，不引用任何外链图片**，保证断网也能完整打开

## 十一、原型真实边界（PRD 12.4 / 13 / 15.2-C）

为避免把演示原型误当成已实现的产品，以下事项**本原型不做**，页面页脚亦有声明：

- ❌ 不做真实账号注册与登录鉴权（切换登录态仅为演示状态机）
- ❌ 不做真实视频上传与真实 AI 分析（点击入口仅给出演示提示）
- ❌ 不伪造任何 AI 评价结果或专家标注对照
- ❌ 不使用后端数据库：数据保存在浏览器 `localStorage`（键名 `thirdeye_p03_demo_v1`），清除浏览器数据或更换设备会丢失，**不代表正式产品的持久化方案**（PRD `5.3.6` `11.3`）
- ❌ 不做未授权访问他人私有资源的服务端校验（PRD `15.1` T-23：该能力由正式版服务端实现，原型不伪装为已实现）

`localStorage` 读写均包在 `try/catch` 中：隐私模式或禁用存储时页面会优雅降级为「暂不可保存」的失败态，而不是白屏报错。
